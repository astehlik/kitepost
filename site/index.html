Kitepost Open the app

Encrypted chat that runs entirely in your browser.

Kitepost is a client for the Delta Chat network, compiled to WebAssembly. Your keys, your messages and the TLS connection to your relay all stay on your device. Nothing to install, and no server ever sees plaintext.

Start chatting How it works

Talks to the Delta Chat apps on Android, iOS and desktop.

Get started in three steps

  1. Create a profile

    Open the app and choose a passphrase. It encrypts your profile in this browser and never leaves it. Pick a display name. A new address is created on the chatmail relay for you, or you can sign in with one you already have. Already using Delta Chat? Import a backup of your profile instead.

  2. Connect with someone

    Press My invite and share the link or QR code, or paste an invite link from someone else under Add contact. The handshake checks both keys, so the contact is verified, not just added.

  3. Chat

    Send messages, pictures and files, create groups and share group invite links. Everything is end-to-end encrypted with OpenPGP, the same way the Delta Chat apps do it.

Delta Chat core in WebAssembly

Encryption, key handling and message formats reuse the Delta Chat core code (rPGP, mail parsing, SecureJoin) compiled for the browser, so messages are fully compatible with the official apps.

TLS ends in your browser

Browsers cannot open mail connections themselves, so a small bridge forwards bytes. The TLS session to your relay runs inside the page and checks the relay's certificate, so the bridge can't read or change anything it forwards.

Encrypted at rest

Your profile is stored in the browser's IndexedDB, encrypted with AES-256-GCM under a key derived from your passphrase. A strict Content Security Policy means only this app's own code runs on the page.

Verified contacts

Invite links carry the inviter's key fingerprint and a one-time secret. Both sides check the keys during the SecureJoin handshake, so a server in the middle can't swap them.

Good to know

Can I use it together with the Delta Chat app on my phone?

Yes, in two ways. Use the same profile: in Delta Chat, open Settings → Chats and media → Export backup, and choose "Import backup file" when setting up Kitepost. Both devices then receive all messages, and what you send or read on one shows up on the other. Or create a separate profile: Kitepost shows a QR code right after setup, and scanning it with Delta Chat on your phone connects the two.

It also works the other way round: Profile → Export backup in Kitepost saves a file that Delta Chat imports with "I already have a profile" → "Restore from backup".

What happens if I forget my passphrase?

The profile can't be recovered, because nobody else holds the key. You can delete it on the unlock screen and create a new one.

Which browsers are supported?

Current versions of Firefox, Chrome, Edge and Safari. Data is kept per browser and device. Private windows forget everything when closed.

Is the browser as safe as a native app?

The cryptography is the same. The trade-off is how the code reaches you: a web app is loaded from this server on every visit, so you trust whoever runs it each time. For the highest assurance, use the native Delta Chat apps or host this client yourself.

Can I host it myself?

Yes. The landing page, the web client and the bridge are three small containers that work behind any reverse proxy and in subdirectories. See the project README for the Docker Compose setup.
