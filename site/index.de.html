Kitepost English App öffnen

Verschlüsselter Chat, der komplett in deinem Browser läuft.

Kitepost ist ein Client für das Delta-Chat-Netzwerk, kompiliert zu WebAssembly. Deine Schlüssel, deine Nachrichten und die TLS-Verbindung zu deinem Relay bleiben auf deinem Gerät. Nichts zu installieren, und kein Server sieht jemals Klartext.

Jetzt chatten So funktioniert’s

Funktioniert mit den Delta-Chat-Apps für Android, iOS und Desktop.

In drei Schritten loslegen

  1. Profil anlegen

    Öffne die App und wähle eine Passphrase. Sie verschlüsselt dein Profil in diesem Browser und verlässt ihn nie. Wähle einen Anzeigenamen. Für dich wird eine neue Adresse auf dem Chatmail-Relay angelegt, oder du meldest dich mit einer vorhandenen an. Du nutzt schon Delta Chat? Dann importiere stattdessen ein Backup deines Profils.

  2. Mit jemandem verbinden

    Tippe auf Meine Einladung und teile den Link oder QR-Code, oder füge unter Kontakt hinzufügen den Einladungslink einer anderen Person ein. Beim Verbindungsaufbau werden beide Schlüssel geprüft, der Kontakt ist also verifiziert und nicht nur hinzugefügt.

  3. Chatten

    Schicke Nachrichten, Bilder und Dateien, erstelle Gruppen und teile Gruppen-Einladungen. Alles ist mit OpenPGP Ende-zu-Ende-verschlüsselt, genau wie in den Delta-Chat-Apps.

Delta-Chat-Core in WebAssembly

Verschlüsselung, Schlüsselverwaltung und Nachrichtenformate verwenden den Code von Delta Chat Core (rPGP, Mail-Parser, SecureJoin), für den Browser kompiliert. Nachrichten sind deshalb voll kompatibel mit den offiziellen Apps.

TLS endet in deinem Browser

Browser können selbst keine Mail-Verbindungen öffnen, deshalb leitet eine kleine Bridge die Bytes weiter. Die TLS-Sitzung zu deinem Relay läuft in der Seite und prüft dessen Zertifikat. So kann die Bridge nichts lesen oder verändern, was sie weiterleitet.

Verschlüsselt gespeichert

Dein Profil liegt in der IndexedDB des Browsers, verschlüsselt mit AES-256-GCM und einem Schlüssel, der aus deiner Passphrase abgeleitet wird. Eine strikte Content Security Policy sorgt dafür, dass nur der eigene Code der App auf der Seite läuft.

Verifizierte Kontakte

Einladungslinks enthalten den Schlüssel-Fingerabdruck der einladenden Person und ein Einmal-Geheimnis. Beide Seiten prüfen die Schlüssel beim SecureJoin-Handshake, damit ein Server dazwischen sie nicht austauschen kann.

Gut zu wissen

Kann ich Kitepost zusammen mit der Delta-Chat-App auf meinem Handy nutzen?

Ja, mit demselben Profil auf beiden Geräten. Öffne in Delta Chat Einstellungen → Chats und Medien → Backup exportieren und wähle beim Einrichten von Kitepost „Backup-Datei importieren“. Danach empfangen beide Geräte alle Nachrichten, und was du auf einem sendest oder liest, erscheint auch auf dem anderen.

Es geht auch andersherum: Auf Servern mit dem Einladungsdienst zeigt Einstellungen → Handy einrichten einen QR-Code, der dein Profil ans Handy übergibt. Anderswo speichert Einstellungen → Backup exportieren eine Datei. Delta Chat importiert beides mit „Ich habe bereits ein Profil“ → „Aus Backup wiederherstellen“.

Was passiert, wenn ich meine Passphrase vergesse?

Das Profil lässt sich nicht wiederherstellen, weil niemand sonst den Schlüssel hat. Du kannst es auf dem Entsperr-Bildschirm löschen und ein neues anlegen.

Welche Browser werden unterstützt?

Aktuelle Versionen von Firefox, Chrome, Edge und Safari. Die Daten liegen pro Browser und Gerät. Private Fenster vergessen beim Schließen alles.

Ist der Browser so sicher wie eine native App?

Die Kryptografie ist dieselbe. Der Unterschied liegt darin, wie der Code zu dir kommt: Eine Web-App wird bei jedem Besuch von diesem Server geladen, du vertraust also jedes Mal dem Betreiber. Für die höchste Sicherheit nutze die nativen Delta-Chat-Apps oder betreibe diesen Client selbst.

Kann ich Kitepost selbst betreiben?

Ja. Startseite, Web-Client und Bridge sind drei kleine Container, die hinter jedem Reverse Proxy und in Unterverzeichnissen laufen. Die Docker-Compose-Einrichtung steht in der README des Projekts.

Kitepost ist ein unabhängiges Projekt, steht in keiner Verbindung zu Delta Chat und funktioniert mit dem Delta-Chat-Netzwerk.
